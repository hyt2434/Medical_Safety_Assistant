\subsection{Purpose}

The purpose of this Software Development Plan is to define
how the Medication Safety Assistant project will be planned,
organized, executed, monitored, and controlled. It serves
as the primary management document for coordinating
development activities and tracking project progress.

The following stakeholders use this plan:

\begin{itemize}

    \item \textbf{Project Manager:}
    To plan project schedules, allocate resources,
    coordinate team activities, manage risks,
    and monitor progress against the plan.

    \item \textbf{Project Team Members:}
    To understand their responsibilities,
    assigned tasks, deadlines, and dependencies
    throughout the development process.

    \item \textbf{Instructors and Teaching Assistants:}
    To review the team's development approach,
    planned deliverables, milestones,
    and project progress.

\end{itemize}


% ==================================================
% 1.2 SCOPE
% ==================================================

\subsection{Scope}

This Software Development Plan describes the overall
development and management plan for the Medication
Safety Assistant project, including project organization,
development phases, iterations, schedules, resources,
deliverables, and project monitoring and control activities.

The plan follows three Rational Unified Process (RUP)
phases: Inception, Elaboration, and Construction,
organized into five two-week sprints.
