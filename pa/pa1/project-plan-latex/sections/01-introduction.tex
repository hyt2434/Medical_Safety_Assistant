\section{Introduction}

\subsection{Purpose}

The purpose of this Software Development Plan is to define how the
Medication Safety Assistant project will be planned, organized,
executed, monitored, and controlled. It serves as the primary
management document for coordinating development activities and
tracking project progress.

The following stakeholders use this plan:
\begin{itemize}
    \item \textbf{Project Manager:} To plan project schedules,
    allocate resources, coordinate team activities, manage risks,
    and monitor progress against the plan.

    \item \textbf{Project Team Members:} To understand their
    responsibilities, assigned tasks, deadlines, and dependencies
    throughout the development process.

    \item \textbf{Instructors and Teaching Assistants:} To review
    the team's development approach, planned deliverables,
    milestones, and project progress.
\end{itemize}

\subsection{Scope}

This Software Development Plan describes the overall development
and management plan for the Medication Safety Assistant project,
including project organization, development phases, iterations,
schedules, resources, deliverables, and project monitoring and
control activities.

The plan follows three Rational Unified Process (RUP) phases:
Inception, Elaboration, and Construction, organized into five
two-week sprints. Detailed activities and tasks for each sprint
are maintained in the corresponding Iteration Plans.

This plan is based on the product requirements defined in the
Vision Document. It covers the development and evaluation of
an educational software prototype, excluding production deployment
and integration with real healthcare systems.

\subsection{Overview}

The remainder of this Software Development Plan is organized
as follows:

\begin{itemize}
    \item \textbf{Section 2 -- Project Overview:}
    Describes the project's purpose, scope, objectives,
    assumptions, constraints, and expected deliverables.

    \item \textbf{Section 3 -- Project Organization:}
    Defines the organizational structure, team roles,
    and responsibilities.

    \item \textbf{Section 4 -- Management Process:}
    Presents the development phases, iteration objectives,
    planned releases, project schedule, resource allocation,
    requirements management, and risk management.
\end{itemize}

Project Estimates (Section 4.1), Reporting and Measurement
(Section 4.3.2), and Configuration Management (Section 4.3.4)
are reserved for later completion, as directed by the PA1
assignment requirements.
