# UI prototype report

- Build: run `xelatex main.tex` from this directory (twice after changing the table of contents).
- Main content: `sections/ui-prototype.tex`.
- Current screenshots: `sections/ui-images/`; regenerate with `npm run capture:report` in `apps/frontend`.
- Original PA1 screenshots: `pa/pa1/ui-prototype/screenshots/` from the repository root.
- Old, unused recaptures: `archive/pa1-recaptures/` (retained for comparison).
- Output: `main.pdf`. PA2 changes are blue; PA1 descriptions are black.

Build with the complete repository. Bundle externally referenced images before uploading only this report to an online LaTeX editor.
