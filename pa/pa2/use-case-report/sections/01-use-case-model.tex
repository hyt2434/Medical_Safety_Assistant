\section{Detailed Use-Case Models}
\label{sec:detailed-use-case-models}

This section presents the detailed use-case models of the Medication Safety
Assistant research prototype. Each diagram corresponds to one use-case
specification, from UC-01 to UC-18. Actors, functions, and conditional
alternative behaviours are shown using UML associations,
\texttt{<<include>>}, \texttt{<<extend>>}, and generalization where applicable.
Labels A1, A2, and so on refer to the alternative flows of the corresponding
specification. These relationships describe functional dependencies;
the specifications define execution order, return steps, and
pre- and post-conditions. HCP review outcomes are simulated.
